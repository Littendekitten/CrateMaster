# CrateMaster weapon images

This folder contains one individually named transparent PNG for every gun in the current CrateMaster catalogue.

- Total: 701 images
- Resolution: 440 × 180 pixels
- Format: PNG with transparent background
- Filename: exact weapon ID from `GUNS`, for example `pistol.png` or `aurora_breaker.png`

The first 64 images use original generated, family-matched game-art sprites; the remaining 637 are exported from the project's individually varied procedural weapon renderer. `manifest.json` maps every weapon ID to its image, display name, rarity, family, and art source.
