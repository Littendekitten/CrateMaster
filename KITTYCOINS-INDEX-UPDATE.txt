CRATEMASTER — KITTYCOINS, PERMANENT INDEX & KITTYGEMS

This project now uses the trusted Render backend for all economic/progression actions. See ANTI-CHEAT-DEPLOYMENT.txt for installation order and full Firestore rules.

- KittyCoins and KittyGems are stored in Firestore, but can only be changed by the Render server's Firebase Admin SDK.
- Player guns, skins, Index discoveries, Index milestone rewards, crate drops, sales, XP, kills, best wave and runs are server-controlled.
- Selling offers Sell 1, Sell extras (keep one) and Sell all. Limited items require exact-name confirmation checked by the server.
- Every 10 new gun discoveries award 10 KittyGems. Selling/trading a discovered gun never removes its Index entry.
- Completing all normal weapons enables a 5% KittyGem bonus chance on Legendary, Limited and GEM-rank weapon drops. Normal completion is recalculated against the current catalogue.
- The KittyGem Store is now a Gem Crate (25 KittyGems per opening), not a single-weapon shop. It has a 50% Common, 25% Rare, 15% Epic, 8% Legendary and 2% GEM-rank drop chance.
- Run rewards are checked against server-issued run tickets, elapsed time, wave limits and plausible spawn/kill limits.

Website files: app.js, firebase.js, index.html, style.css.
Render files: server/index.js, server/catalog.json, server/package.json, server/render.yaml.
Firebase rules: firestore.rules.

Keep your existing images/coin.png. Existing Firestore coin balances remain in the `coins` field internally and are displayed as KittyCoins.
